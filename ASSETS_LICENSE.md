# Rendering asset provenance

## Original assets created for this project

| File | Source / method | Rights and restrictions |
|---|---|---|
| `assets/rendering/arena-original.hdr` | Original analytic arena lighting, generated by `scripts/generate_render_assets.py`; 512×256 linear radiance encoded as RGBE | Original project data; no downloaded photographs, scans or third-party asset license. Not a Poly Haven asset. |
| `assets/rendering/contact-shadow.rgba` | Original radial opacity function, generated by the same script; 64×64 RGBA8 | Original project data; no third-party asset license. Stylized baked opacity decal, not physically baked character AO. |
| Ring ceiling fixtures | Original instanced boxes in `js/Ring.js` | Original procedural geometry; no third-party model. |

Regenerate with `python3 scripts/generate_render_assets.py`. Exact sizes and SHA-256 hashes are in `assets/rendering/manifest.json`; the standalone build checks both. These originals have not been mislabeled as externally licensed CC0 assets. No commercial asset purchases or model downloads were made.

The HDR is intentionally a small, lossless Radiance file (524,337 bytes), not KTX2 or RGBE PNG. This is a documented Phase 1 deviation. Numerical radiance and opacity data were generated as data, without a generative-image service. This does not provide scanned PBR textures or a photoreal human mesh.
